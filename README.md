# Resume RAG

A full-stack web application that allows users to upload and analyze resumes through a simple interface.
The project is built with a **React frontend** and **Node.js backend**, and the entire application is containerized using Docker for easy deployment.

---

## 🚀 Features

* Upload and manage resume files
* User-friendly frontend interface
* REST API backend for processing requests
* File upload and storage functionality
* Containerized deployment using Docker
* Full-stack architecture with separate frontend and backend services

---

## 🐳 Running the Project with Docker

Clone the repository:

```
git clone https://github.com/Charan08Teja/resume-rag.git
cd resume-rag
```

Build and start the containers:

```
docker-compose up --build
```

This will start both the **backend** and **frontend** services.
